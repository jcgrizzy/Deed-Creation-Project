# Deed-Creation-Project

The purpose of this project is to build a workflow and intaking system for deeds, and this will be later connected to an agent that can assist in quickly creating deeds.

## Layout

```
CLAUDE.md                     Project brief and rules — start here
config/firm.json              Fees, payment link, firm settings
spec/intake-fields.md         Intake field list (merge-field IDs)
spec/routing-rules.md         STOP / FLAG conditions
spec/workflow-stages.md       File stages and owners
spec/florida-requirements.md  Execution & recording checklist (attorney-verified status)
spec/cognito-build.md         Cognito Forms build instructions for the intake form
design/                       Approved intake form mockup
templates/                    Client intake emails (EN/ES); deed templates to come
samples/                      Fictitious test records only
```

## Contributing

Branch from `main`, open a pull request, and request review. Do not commit real client data or credentials.
